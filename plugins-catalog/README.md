# mogram-plugins

Каталог плагинов для [Mogram](https://github.com/TUHS-lab/mogram). Клиент читает `index.json`, проверяет подпись `index.json.sig` ключом Mogram и сверяет хеш каждого файла.

Плагин ставится из окна «Плагины» → «Магазин плагинов». Перед установкой клиент показывает, какие права просит плагин.

Добавить свой плагин: pull request с файлом в `plugins/`. Каталог пересобирает и подписывает владелец: `./sign.sh`.

Пишешь свой плагин: [DEVELOPING.md](DEVELOPING.md) (отладка с автоперезагрузкой, оверлеи, геометрия интерфейса, события) и [SPEC.md](SPEC.md) (контракт).
Проверка файла без запуска: `python3 lint.py my.plugin`.
