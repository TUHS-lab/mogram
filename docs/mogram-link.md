# Mogram Link (протокол MGL1)

Связь ПК и телефона Mogram через закрытый канал «Mogram Link» в вашем аккаунте Telegram. Своего сервера нет: сообщения идут через Telegram, шифруются на устройстве.

## Канал
Закрытый канал с названием `Mogram Link` и описанием `mgl1`, создатель вы. Каждое устройство ищет такой канал среди своих (`contacts.search`), если нет, создаёт.

## Сообщение
Текст: `U+2063 "mgl1:" + base64url(iv[12] + AES-256-GCM(json) + tag[16])` (base64url без `=`).
Ключ: PBKDF2-HMAC-SHA1(пароль связи, соль `"mgl1:" + id пользователя`, 200000 раундов, 32 байта). Пароль один на всех устройствах и нигде не передаётся.

## Поля json
`t` тип, `d` id устройства-отправителя, `ts` время в миллисекундах.

| t | Данные | Жизнь |
| --- | --- | --- |
| `clip` | `text` (до 2000 символов) | удаляется отправителем через 90 с |
| `now` | `title`, `artist`, `sc` | через 90 с |
| `act` | `chat` (id диалога в формате Telegram Android, 0 = не читаю) | через 90 с, пульс раз в 15 с |
| `state` | `notes` {userId: текст}, `tags` {userId: тег}, `pins` [id диалогов] | хранится, предыдущая версия удаляется |

Id диалогов: пользователь `+id`, чат `-id`, канал `-1000000000000 - id`.
Свои сообщения (`d` равен своему устройству) игнорируются. Состояние побеждает по `ts` (последняя запись).
